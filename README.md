# Fubo Movies — public deploy

Live page: **https://escully-cpu.github.io/fubo-movies/**

Public-facing mirror of the rendered Fubo movies catalog. Source code (generator, scraper, audit, snapshots) lives in a separate private repo; this repo contains only the rendered HTML and the logo asset.

Updates land here when the local generator is re-run and a new `index.html` is copied in + pushed.
